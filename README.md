## Getting Started

### Prerequisites

- Git
- A runtime appropriate for the stack listed above

### Installation

```bash
git clone https://github.com/RaghavSobti37/shrim-exports-website.git
cd shrim-exports-website
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
